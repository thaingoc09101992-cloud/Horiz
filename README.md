# HORIZ Commerce

Storefront bán giày & thời trang HORIZ: React + TypeScript + Vite, Supabase (Postgres / Auth / Storage), triển khai trên Cloudflare.

Tài liệu dự án nằm trong thư mục [`documents/`](documents/README.md).

## Chạy dev

```bash
npm install
npm run dev
```
